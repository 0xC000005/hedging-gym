# Counterfactual terminal-risk updates

The [counterfactual extension](../src/hedging_gym/extensions/counterfactual.py)
updates a hybrid hedger's HOLD/TRADE probabilities while freezing continuous
sizes and the value network. It reuses
[HybridPolicy](../src/hedging_gym/baselines/hpo.py), market banks and the common
cash ledger. For simultaneous sizing updates, see
[joint counterfactual updates](joint-counterfactual.md).

## Sources and mechanism

The method combines established ideas from
[Expected Policy Gradients](https://jmlr.org/papers/v21/18-012.html),
[input-dependent baselines](https://openreview.net/forum?id=Hyg1G2AqtQ), and
[counterfactual credit assignment](https://proceedings.mlr.press/v139/mesnard21a.html).
Its hybrid policy comes from the finance adaptation of
[HPO](https://arxiv.org/abs/2605.14297), with the
[author optimizer pinned at e48ae86](https://github.com/MatiasAlvo/hybrid-rl/blob/e48ae86da1e8f14c93cbb56e48d87f8674228659/src/algorithms/hybrid/optimizer_wrappers/hybrid_wrapper.py).
This categorical-only update does not reproduce HPO's full mixed-gradient recipe.

At one uniformly sampled decision date, a causal policy prefix reaches the
intervention state. The `all_mode` arm rolls every mode to settlement; the
`sampled` arm rolls one mode per prefix. Branches share market shocks and future
random uniforms, but subsequent actions depend on each branch's own holdings.
Every branch receives its complete cost-inclusive terminal loss.

Training differentiates a probability-weighted sum of terminal costs at one
fixed, training-calibrated ES threshold. The sampled comparator receives more
independent prefixes to approximately match decision-ledger work. Both collect
fresh on-policy histories after each update. No future path enters the deployed
policy's observations.

## Supported inputs

The extension supports the continuous hybrid policy with finite holding bounds
and pre-maturity decisions. It rejects trade lots, minimum-order sizes and
trading at maturity. The supplied comparison uses terminal ES with `basic` or
`operational_fixed` execution settings.

The runner requires a trusted qualification directory with:

- `train_bank.pt` and `development_bank.pt`: `config`, `spot`, `variance`,
  `marks` and `liability` fields, with distinct generation seeds recorded.
- For `basic`: `policies/hpo-seedN/step-3000.pt` for every requested seed.
- For `operational_fixed`:
  `policies/operational_fixed/hpo-seedN/step-1000.pt`.

The banks are not generated by this command. With those banks already present,
`benchmarks.qualify_policies` creates the required snapshots; for example:

```bash
uv run --frozen python -m benchmarks.qualify_policies \
  --run-dir /path/to/qualification --methods hpo --preset operational_fixed \
  --seeds 7 17 29 --updates 1000 --device cpu
```

Use `--preset basic --updates 3000` for the basic snapshots. Current checkpoints
must match their explicit configuration; historical artifacts require their
matching source version.

## Run and inspect

Choose a new output directory outside both the repository and source directory:

```bash
uv run --frozen python -m benchmarks.qualify_counterfactual \
  --source-dir /path/to/qualification --output /path/to/counterfactual \
  --preset operational_fixed --seeds 7 17 29 \
  --updates 100 --batch-size 64 --device cpu
uv run --frozen python -m benchmarks.review_counterfactual \
  --runs /path/to/counterfactual --output /path/to/counterfactual-review.json
```

The runner rejects an existing output directory. It saves configurations,
checkpoints, work counts and development trade tapes. The review reconstructs
losses with independent NumPy accounting and checks reported ES. Sampled and
greedy deployment are reported separately.

```bash
uv run --frozen pytest -q tests/test_counterfactual.py
```

These tests cover branch accounting, action-specific tail costs and exact
categorical-gradient identities. All-mode integration need not reduce variance
per unit of computation: extra independent market paths can be more useful.
Report decision steps, liquidations, backward work and elapsed time separately.
Fixed-fee studies also require the action-precision checks described in
[joint counterfactual updates](joint-counterfactual.md#fixed-fees-and-precision).
